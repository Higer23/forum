# Higum Forum

A static discussion forum with Firebase authentication and a Firebase Realtime Database backend.

## English

**What it does:** Users can register and sign in with email and password or Google, verify their email address, browse topics and post in them.

**Setup**
1. Create a Firebase project and enable Email/Password and Google sign-in.
2. Put your project settings into firebase-config.js.
3. Restrict the API key in the Google Cloud console (Credentials).
4. Serve the folder with any static server, for example: python -m http.server

## Deutsch

**Funktion:** Nutzer koennen sich mit E-Mail und Passwort oder mit Google registrieren und anmelden, ihre E-Mail-Adresse bestaetigen, Themen lesen und darin Beitraege verfassen.

**Einrichtung**
1. Firebase-Projekt anlegen und E-Mail/Passwort sowie Google-Anmeldung aktivieren.
2. Die Projekteinstellungen in firebase-config.js eintragen.
3. Den API-Schluessel in der Google Cloud Console (Anmeldedaten) einschraenken.
4. Den Ordner mit einem beliebigen statischen Server bereitstellen, z. B.: python -m http.server
